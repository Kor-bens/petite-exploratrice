# Petite Exploratrice

Jeu éducatif 4 ans : espace 3D, sciences, métiers, histoire, géographie.

Repo : https://github.com/Kor-bens/petite-exploratrice

## Relier à Netlify (une fois)

1. https://app.netlify.com/start
2. Import from Git → GitHub → `Kor-bens/petite-exploratrice`
3. Publish directory : `.`
4. Deploy

Le site sera du type `https://exploratrice.netlify.app` si tu réutilises ce nom, sinon Netlify en donne un nouveau.
